# Security

MINIMALSOFT TOOLWORKS TECHNOLOGIES takes the security of its software and infrastructure seriously.

## Public Repository Boundary

This repository is intentionally limited to public documentation and non-sensitive product information.

The following must never be committed here:

- API keys
- Access tokens
- OAuth client secrets
- Private keys
- Passwords
- Database credentials
- Production environment variables
- Customer data
- Private source code
- Internal infrastructure secrets

## Reporting a Security Issue

If you discover a security issue involving a MinimalSoft product, please do not publish sensitive details in a public issue.

Contact:

**contact@minimalsofttoolworks.com**

Please provide enough information to reproduce or understand the issue without exposing credentials or personal data.

## Production Systems

Production credentials and private application code are maintained outside this public repository.

Security-sensitive configuration should remain in appropriate secret-management or deployment systems.
